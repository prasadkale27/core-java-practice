## ✅ Threads in JVM (Examples)

**In the JVM, multiple system and user threads run together.**

### 🔹 1. Main Thread

* Created by the JVM when the program starts
* Executes the `main()` method
* It is a **user (non-daemon) thread**
* Program **does not terminate** while main thread is running

```java
public static void main(String[] args) {
    // executed by main thread
}
```

---

### 🔹 2. Garbage Collector (GC) Thread

* Created automatically by the JVM
* Runs in the **background**
* Frees unused memory (heap)
* It is a **daemon thread**
* JVM can exit even if GC thread is running

---

### 🔹 3. Other JVM System Threads

Examples:

* **Finalizer thread**
* **Reference handler thread**
* **Signal dispatcher thread**
* **JIT compiler thread**

All are **daemon threads**.

---

## 🧠 Important Difference (Interview Favorite)

| Main Thread      | GC Thread               |
| ---------------- | ----------------------- |
| User thread      | Daemon thread           |
| Runs `main()`    | Runs in background      |
| Keeps JVM alive  | Does not keep JVM alive |
| Created at start | Created by JVM          |
